# Issue #14 — bounded installation and digital-twin implementation

## Outcome

Land the deterministic, release-oriented installation contracts that can be
proved without a venue. Keep every physical claim fail-closed until an external
venue supplies an approved configuration, exact hardware/calibration receipts,
three human-observed wall-plug recovery proofs, and a clean restore rehearsal.

## Implementation

1. Bind a reference digital twin to the exact projector/camera, score, program,
   room-layout, interaction, and projection-probe bytes already on `main`.
2. Define deterministic projector/surface geometry, multi-output frame tickets,
   speaker routing, calibration order, thresholds, hardware roles, and bounded
   recovery policy. Label all unmeasured geometry and equipment assignments as a
   reference simulation rather than venue evidence.
3. Add strict schemas and a Python validator for the twin, gate ledger, archive
   disposition, venue evidence, runtime admission, calibration, wall-plug proof,
   and restore phases.
4. Add an on-demand foreground supervisor. It launches only an exact command
   admitted by venue evidence from a verified canonical release root, emits
   JSONL health telemetry, and enforces a bounded restart window. It does not
   install or generate a LaunchAgent, daemon, cron entry, or other host service.
5. Document setup, calibration, operation, wall-plug rehearsal, strike,
   transport, troubleshooting, restore, and conservation from a clean release.
6. Port or reject every claim in the archived Limen installation proposal in a
   new derivative disposition. The immutable archive census remains historical;
   the archived proposal is never treated as authoritative venue evidence.
7. Add adversarial regressions, integrate two visible portable invariants, and
   run the complete portable and Apple Metal batches on one exact tree.

## External gates that remain blocked

- venue dimensions, egress, mounting, power, ventilation, and safety approval;
- exact projector, surface, display-host, interface, speaker, cabling, and power
  inventory;
- measured registration, output skew, audiovisual skew, routing, level, and
  thermal behavior;
- a venue-approved canonical-release launcher and health endpoint;
- three distinct human-observed wall-plug recovery receipts;
- setup, strike, clean restore, and human-visible plane/cue acceptance receipts.

No green fixture or simulator result may close issue #14 or be described as a
physical installation proof.
