## Verification and acceptance

Every exact source tree runs:

```bash
python3 scripts/check-danse.py
python3 scripts/tests/danse-delivery.test.py
python3 -m py_compile render/*.py pipeline/*.py sound/*.py submission/*.py scripts/*.py
node --check sound/control.mjs
bash -n done.sh
python3 render/browser.py --check --verify --arrival --probe
```

Pages tests cover allowlisting, digests, symlinks, stale/private path exclusion,
HUD hidden-at-load, keyboard/touch disclosure, ARIA state, mobile layout,
reduced motion, internal links, and deployed-SHA verification.

Score tests prove identical audio events and visual state for score/seed/time,
cue tolerances, seek/segment/concat/restart/live/offline parity, and
audio-disabled determinism.

Package acceptance requires `done.sh --phase package`, explicit human
attestations, two-device checksums, and later uploaded/submitted phase success.
Cleanup requires full checksums, restore rehearsal, a redacted custody receipt,
and ancestry/remote checks before deleting any material worktree. No invariant
floor, provenance threshold, destructive gate, or human approval may be
weakened to make a phase pass.

## Human and external gates

presentation, not just code completion. Useful archive work reaches `main` only
through deliberate ports.

account actions, filing terms, fees, contracts, public sends, physical

remain Anthony or external gates. All reversible implementation, research,
