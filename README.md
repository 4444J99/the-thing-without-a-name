# Archived Danse continuation

This repository is an archived continuation of Danse Macabre. It is no longer a
source of public or deployable Danse code.

- canonical source: <https://github.com/organvm/the-thing-without-a-name>
- public artwork: <https://danse.pages.dev/>

No new work should land here. The repository remains available so its complete
development history and the work reconciled into the canonical repository stay
recoverable.
